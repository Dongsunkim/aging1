# 한국 이용자를 위한 얼굴 나이 모델 검증 계획

**구현 상태: 한국 사용자 대상 연령 데이터 평가 도구 준비 완료 · 한국인 전용 모델 미적용.**

## 목적과 현재 한계

‘몇살로보여?’는 한국 이용자가 주로 사용할 앱이므로, 실제 촬영 나이가 확인된 **국내 수집 얼굴 사진**을 기준으로 모델을 검증하는 것이 타당합니다.

그러나 현재 서비스의 FaceRes/SSR-Net/GEAR 모델은 **한국인 얼굴만을 학습했다고 확인되지 않은 범용 모델**입니다. 얼굴 사진만으로 국적이나 한국인 여부를 판정할 수도 없습니다. 따라서 한국인 얼굴을 분석했다고 주장하거나, 한국인 평균으로 나이를 임의 보정해서는 안 됩니다.

## 실제 활용 가능한 한국 연령 라벨 데이터

- **AI허브 데이터명:** 안면 인식 에이징(aging) 이미지 데이터
- **데이터셋 번호:** 71415
- **공식 URL:** https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=71415
- **공개 규모:** 약 50,250장의 얼굴 이미지와 라벨링 JSON
- **중요한 항목:** `age_past`(촬영 당시 나이), `age_now`(현재 나이), 참가자 식별, 사진, 얼굴 위치
- **공개된 활용 모델:** C3AE 나이 추정 모델. 데이터셋 소개 페이지에 MAE 3.96이 보고되지만, 현재 앱과 다른 평가 조건이며 **본 서비스의 실제 성능을 의미하지 않습니다.**
- **이용 절차:** AI허브 계정 및 해당 데이터셋 다운로드 신청/승인 필요
- **이용 조건:** AI허브 정책에서 허용하는 승인 목적에 한정해 사용하고 출처 표기 의무 준수. 원본 사진·라벨 등 데이터 자체를 GitHub, Vercel, 앱 번들로 재배포하지 않습니다.

출처: https://aihub.or.kr/aihubnews/faq/list.do

## 승인된 데이터로 진행할 작업

1. 해당 데이터셋을 적법하게 신청·승인받습니다. **사진/JSON 원본을 이 저장소에 업로드하지 않습니다.**
2. 사진을 분석한 결과를 내부 개발 환경에서만 CSV로 생성합니다. CSV에는 실제 사람 이름·원본 파일경로·이미지 내용 대신 **가명 참가자/사진 키**만 사용합니다.
3. 학습에 이용한 참가자와 평가 대상 참가자를 **동일 인물 기준으로 완전히 분리**합니다. 같은 사람의 다른 시기 사진이 양쪽에 포함되면 평가가 과대해질 수 있습니다.
4. 현재 세 모델 FaceRes, SSR-Net, GEAR와 서비스의 중앙값(ensemble), 향후 라이선스가 확인된 대안 모델을 동일한 테스트 구간에서 비교합니다. 촬영 당시 나이(`age_past`)를 정답 기준으로 사용합니다.
5. 전체 평균절대오차(MAE), 연령대별 MAE, 나이 과소 예측, 30대 이상 얼굴을 17세 이하로 분류한 사례를 확인합니다.
6. 충분한 평가 증거가 있고 앱인토스 라이선스/성능 검사를 통과한 경우에만 특정 모델을 선택해 **별도 릴리스**합니다. 현재 앱에 자동 보정값을 주입하지 않습니다.

## 평가 CSV 형식 (승인된 내부 자료만)

열 이름:

```csv
dataset_id,approved_use,subject_key,image_key,age_at_capture,faceres_age,ssrnet_age,gear_age
AIHUB-71415,yes,SYNTHETIC_PERSON_001,SYNTHETIC_IMAGE_001,39,26.2,33.1,28.4
```

위 행은 사용 방법을 설명하기 위한 **가상의 숫자**이며 실제 평가용 데이터가 아닙니다. 반드시 권한과 목적이 확인된 데이터만 사용하세요.

### 실행 명령어

```bash
node tools/korean-age-eval.mjs --csv /private/approved-korean-age-predictions.csv --output /private/korean-age-summary.json
```

평가 도구는 외부 네트워크 요청이 없고, **집계치만 JSON으로 기록**합니다. 사진, 참가자 식별자, 원본 경로는 보고서에 포함되지 않습니다.

평가 기준은 최소 400장, 서로 다른 참여자 100명, 0~19/20~34/35~49/50세 이상 각 연령 구간 최소 20장입니다. 이는 **검증된 정확도 임계값이 아니라 샘플 부족을 방지하는 내부 최소 기준**입니다. 실제 출시 전에는 독립 시험과 더 큰 표본이 필요합니다. 대체 모델은 전체 MAE를 0.5세 이상 개선하고, 연령대별 성능을 크게 저하하지 않으며, 심각한 나이 과소 추정을 증가시키지 않아야 리뷰 후보가 됩니다.

현재 도구는 **세 모델과 현행 중앙값 방식의 집계 오차를 비교해 모델 선택 후보만 제시**합니다. 직접 릴리스/배포/나이 보정을 수행하지 않습니다.

## 반드시 피할 방법

- 구글·네이버에서 얼굴 사진을 자동 수집해 실제 나이를 추측하는 방법
- 사진의 얼굴 모양만 보고 국적/한국인 여부를 분류하는 방식
- 사용자가 입력한 실제 나이에 맞춰 정답처럼 숫자를 돌려주는 방식
- 한국인 사진을 사용했다고 검증되지 않은 범용 모델을 ‘한국인 전용’으로 홍보하는 방식

## 참고

국내 데이터 신청 여부·이용 조건·개인정보 영향평가는 최종 운영자가 확인해야 합니다. 해당 데이터의 사용 허가를 받았다고 해서 모든 사진을 공개 저장소나 미니앱에 내장할 권한이 생기는 것은 아닙니다.
