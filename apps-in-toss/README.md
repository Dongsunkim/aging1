# 몇살로보여? — 앱인토스 미니앱 준비 프로젝트

이 폴더는 **기존 Vercel 사이트를 훼손하지 않고** 앱인토스용 WebView 미니앱을 만들기 위한 별도 프로젝트입니다.
원본 화면과 얼굴 나이 분석 프로그램은 저장소 최상위 `index.html`, `style.css`, `app.js` 등을 참조합니다.
`npm run prepare` 명령으로 원본 화면을 가져오며, 핵심 **결과 보기** 버튼은 토스 디자인 시스템(TDS) 컴포넌트로 표시합니다.

## 반드시 확인할 설정

1. **앱인토스 콘솔**에서 비게임 미니앱을 먼저 생성합니다.
2. `apps-in-toss.config.ts`의 **appName은 `agingwonder`**로 설정했습니다. 앱인토스 콘솔의 식별자와 동일한지 확인하고, 한글 노출 이름은 ‘몇살로보여?’로 설정하세요.
3. 앱 아이콘·설명·스크린샷·연락처와 개인정보 안내 등 콘솔의 필수 제출 항목은 개발자가 직접 등록해야 합니다.
4. Node.js **24 이상** 환경에서 명령을 실행하세요.

## 설치와 빌드

프로젝트 루트(최상위)가 아닌 **`apps-in-toss` 폴더 안에서** 실행합니다.

```bash
cd apps-in-toss
npm install
npm run dev
```

개발 화면 점검 이후:

```bash
npm run build
```

`build`는 기존 웹사이트의 최신 화면을 변환한 뒤 Vite 웹 번들과 **앱인토스 `.ait` 미니앱 번들** 생성을 시도합니다.
패키지 설치와 `.ait` 빌드는 실제 인터넷·Node 24·콘솔 설정이 있는 환경에서 최종 확인해야 합니다.
생성된 `.ait` 파일은 앱인토스 콘솔에 업로드하고 **QR 실기기 테스트**를 거쳐 검수를 요청하세요.
`npm run deploy`는 실제 앱인토스 계정·권한이 연결된 뒤에만 사용하세요. 이 저장소를 Vercel에 배포한다고 토스에 자동 출시되지는 않습니다.

## 기존 웹앱과의 관계

- 기존 서비스: https://aging-omega.vercel.app/
- 기존 웹사이트의 정적 HTML은 **저장소 최상위**에 유지합니다.
- 앱인토스 전용 파일은 `apps-in-toss/` 아래에만 있습니다.
- `scripts/prepare.mjs`이 기존 HTML의 분석 버튼을 **TDS 버튼**으로 감싸고 Vite 진입 파일을 생성합니다.
- 원래 분석 동작을 담당하는 기본 버튼은 숨기며, 상태와 클릭 이벤트는 연결돼 있습니다.
- 원본 프로그램의 UI 변경으로 HTML 마크업이 달라지면 변환 스크립트가 오류를 내고 중단하여 잘못된 화면이 조용히 빌드되지 않게 했습니다.

## 앱인토스 심사 전 체크리스트

- [x] 앱인토스 콘솔의 **실제 appName(`agingwonder`)**을 설정에 반영
- [ ] 콘솔에 앱의 한글 이름, 아이콘, 서비스 설명, 스크린샷 등록
- [ ] Node 24 이상에서 `npm install` 및 `npm run build` 성공 확인
- [ ] Android·iOS 토스 앱 QR 테스트에서 **사진 선택 → 남성/여성 선택 → 결과 보기 → 나이·피부 정보 출력** 확인
- [ ] 피부/모발 모델이 외부 CDN에서 정상 로딩되는지, 모바일 메모리 문제 없는지 확인
- [ ] 디자인 시스템, 내비게이션/안전영역, 로딩, 오류 메시지, 접근성 검토
- [ ] 외모 평가 표현이 신체/성별을 조롱하거나 건강을 단정하지 않는지 심사 기준에 맞게 점검
- [ ] 개인정보 처리방침과 외부 모델·라이브러리, 사진 처리 방식, 운영자 연락처 점검
- [ ] 자바스크립트 번들에 원하지 않는 `eval` 및 동적 코드 실행 등 심사 문제 소지가 있는지 확인
- [ ] 실제 등록은 콘솔에서 앱 검수 후 진행

## 사진 및 개인정보 관련 주의

현재 웹앱은 사용자가 선택한 사진을 **브라우저에서 처리**하도록 설계했으며, 자체 사진 업로드 서버를 운영하지 않습니다. 다만 AI 라이브러리와 모델은 외부 서버에서 다운로드하므로 실제 운영에서는 네트워크 요청, 라이브러리의 전송 여부, 개인정보 안내 내용을 별도 점검해야 합니다.

사진만으로 피부질환·모발 밀도·건강을 진단할 수 없으며 외모 나이는 오락용 추정치입니다. 성별 선택은 필수 입력이지만 추정 나이를 임의 보정하지 않습니다.
