# 몇살로보여? — 웹앱 한글판 8.4

**사진과 필수 성별을 입력하면 AI 외모 나이를 추정하고, 표정·주름과 유사한 잔선·피부 밝기·가시적 머리카락 영역을 함께 설명하는 웹앱**입니다. 모바일과 컴퓨터를 모두 지원하며 별도 서버 없이 정적 호스팅할 수 있습니다.

## 7.0에서 개선한 화면과 피부 관리 상식

- **성별 필수 선택은 남성·여성만 제공합니다.**
- 사진 분석이 기기 내부에서 이뤄진다는 안내는 화면 맨 위에 한 번만 표시합니다. 상단 추가 표기와 맨 아래 중복 안내를 없앴습니다.
- **‘근거 자료 확인’ 버튼과 링크 문구는 웹앱 화면에서 삭제**했습니다.
- 결과 화면의 피부 관리 상식은 피부 타입과 성분 선택에 도움이 되는 다음 6개 주제로 바꿨습니다.
  - 건조한 피부: 세라마이드·글리세린·히알루론산, 크림과 젤 제형 차이
  - 잔주름: 레티놀·레티노이드 사용 간격, 자외선 차단, 임신 시 사용 금지
  - 잡티·색소침착: 산화철이 들어간 색조 자외선 차단제의 역할
  - 막힌 모공·블랙헤드: 살리실산과 과도한 각질 관리 주의점
  - 새 화장품: 팔 안쪽에서 7~10일간 미리 시험하는 방법
  - 피부 타입별 보습제: 지성·건성·복합성에 따른 제형 선택
- 해당 지식은 **모든 사용자에게 동일하게 표시하는 일반적인 정보**입니다. 사진만으로 피부 수분량이나 질환을 추정하거나 피부 상태에 맞춘 치료를 권하는 기능은 아닙니다.

## 개선판 8.4: 사진 품질·피부 관찰의 오판 방지

- 얼굴에 비친 빛이 심하게 날아가거나 검게 뭉치는지, 얼굴 영역이 너무 작은지, 사진의 초점이 의심스러울 정도로 흐린지, 얼굴이 프레임 가장자리에서 잘렸는지를 **기기 내에서 검사**합니다.
- 이런 촬영 문제가 감지되면 **추정 나이 숫자는 그대로 보여주고** 결과에 촬영 품질 주의를 표시하지만, 피부결과 색감은 확정적으로 평가하지 않고 사진 상태 안내와 기본 피부 관리 상식으로 전환합니다.
- 이전에는 피부 분할 영역 중 얼굴 중앙·아래까지 여러 픽셀을 사용했습니다. 이번에는 **양쪽 볼에 가까운 제한된 영역**에 분석을 집중해 머리카락·코 주변 그림자·기타 얼굴 구조 영향이 과도하게 섞이지 않도록 했습니다.
- 양쪽 볼의 조명 차이가 크면 그 차이를 피부 고유의 색감 편차로 해석하지 않고 **조명 재확인을 우선 안내**합니다.
- 사진 품질 검사는 색상/밝기/명암/흐림에 관한 **휴리스틱(비임상적 규칙)**이며, 실제 피부 상태나 정확한 나이의 확률을 산출하지 않습니다. 일부 정상 사진도 흐리다고 잘못 분류할 수 있습니다.
- 사진을 다시 찍을 때는 정면, 자연스럽고 고른 조명, 충분한 얼굴 크기, 낮은 필터/보정 강도를 권장합니다.
- 이 버전은 **오판 가능성을 줄이기 위한 입력 검사와 개인화 가이드 안전장치**를 추가한 것으로, 실제 나이 추정 MAE가 개선됐다고 검증된 버전은 아닙니다.
- 한국인의 실제 연령이 알려진 평가 데이터를 확보하면 기존 8.1의 `tools/korean-age-eval.mjs`로 모델 교체 전후 연령대별 오차를 확인해야 합니다.

관련 코드: `photo-quality.js` · `visual-analysis.js` · `skin-personalization.js` · `tests/photo-quality.test.mjs`.

## 개선판 8.3: 사진 분석 기반 피부 관리 가이드

기존에는 모든 이용자에게 같은 피부 건강 상식 6개를 표시했습니다. 이번 버전부터는 사진에서 관찰 가능한 특징에 따라 **4개의 맞춤 관리 정보 카드**를 보여줍니다.

- 얼굴의 **피부 명암 분포, 밝기 편차, 미세한 표면 무늬, 밝게 반사된 픽셀, 조명 상태**에 따라 안내의 우선순위가 달라집니다.
- 카드마다 **어떤 사진 단서를 참고했는지** 적고, AAD(미국피부과학회)의 관련 자료 원문을 연결합니다.
- 피부 분할 모델을 사용할 수 없는 경우, 조심스럽게 **양쪽 볼 영역의 표본**만 비교하며 측정의 제한을 고지합니다. 영역이 피부가 아닐 수 있으므로 정밀 측정으로 해석할 수 없습니다.
- 사진으로 확인할 수 없는 **수분량·피지량·민감도·진짜 주름·모공 상태·여드름·색소침착·피부질환은 측정하거나 진단하지 않습니다.** 제품의 선택은 실제 피부 느낌과 제품 설명을 함께 고려해야 합니다.
- 결과는 계속 기기에서 계산하며, 사진이나 추정 결과를 앱 자체 서버에 전송하거나 저장하지 않습니다. 모델 파일 다운로드를 위해 외부 자원 서버에는 접속할 수 있습니다.
- 나이 추정에는 기존 세 모델 집계 방식을 유지하며, 피부 관찰 특징을 임의로 나이 숫자에 가중 적용하지 않습니다.

맞춤 추천 구현: `skin-personalization.js` · 얼굴 피부 픽셀 관찰: `visual-analysis.js` · 회귀 테스트: `tests/skin-personalization.test.mjs`, `tests/skin-appearance.test.mjs`.

## 개선판 8.2: 숫자로 나이 판단하기

- 사진에서 얼굴 한 명을 정상 인식하고 나이 모델이 하나라도 유효한 추정을 반환하면 **'판단 어려움' 대신 외모 나이 숫자**를 표시합니다.
- FaceRes, SSR-Net, GEAR **최대 세 모델**을 순서대로 분석합니다. 세 모델이 유효하면 예측값의 중앙값, 둘만 유효하면 중간값, 하나만 유효하면 해당 값을 표시합니다.
- 모델 간 최대 예측 차이와 실제 나이의 측정치가 아니라는 참고 문구는 결과 하단에 계속 표시합니다.
- 한 모델의 16세 같은 극단적인 결과만을 정답으로 단정하는 위험을 줄이기 위한 임시 집계입니다. **집계 후 정확도가 실제로 높아졌다고 검증된 것은 아닙니다.**
- 한국인 얼굴 사진만으로 학습하거나 국내 나이 데이터로 보정한 모델은 아닙니다. 승인된 한국인 나이 라벨 데이터로 정확도를 확인한 후에야 성능을 주장할 수 있습니다.
- 외부 얼굴 모델/기기 성능이 제한되면 일부 모델 추정이 실패할 수 있습니다. 모든 모델이 실패하거나 얼굴을 찾지 못하면 숫자를 지어내지 않고 오류를 표시합니다.

## 개선판 8.1: 한국 이용자 기준 평가 준비

국내 이용자의 나이 추정을 더 적절하게 검증하기 위해 AI허브 **안면 인식 에이징(aging) 이미지 데이터(71415)**로 범용 모델을 평가할 수 있는 오프라인 집계 도구를 추가했습니다.

- `tools/korean-age-eval.mjs`: 사용 승인이 확인된 한국 얼굴 데이터에서 촬영 당시 나이와 모델 예측값을 비교해 MAE, 연령별 과소 예측 등을 계산합니다.
- `tests/korean-age-eval.test.mjs`: 승인 상태, 표본 부족, 편향과 개인정보 비노출을 점검합니다.
- `docs/KOREAN_AGE_BENCHMARK.md`: 데이터 신청·승인·모델 재학습·배포 기준을 설명합니다.
- **중요:** AI허브 데이터 승인 및 실제 모델 학습/교체는 아직 수행하지 않았습니다. 현재 서비스가 한국인 사진만으로 직접 나이를 비교한다고 주장하지 않으며, 한국인/국적을 얼굴에서 판단하지도 않습니다.
- 데이터의 원본 사진과 라벨은 GitHub/Vercel/앱인토스 파일에 포함하지 않습니다.

## 개선판 8.0: 나이 모델 간 예측 차이 표시

이전 모델이 여러 사진에서 **16세**로 반복되는 사례가 있어, 서로 다른 구조의 두 나이 모델을 실제 사진으로 교차 시험했습니다.

- 기본 **FaceRes** 모델과 보조 **SSR-Net** 모델을 순차적으로 실행합니다. 두 모델 모두 브라우저 내부에서 사진을 처리합니다. 외부로 업로드하는 기능은 없습니다.
- 8.0 구버전에서는 모델 간 12세 이상 차이나 반복 예측 시 **‘판단 어려움’**을 표시했지만, **8.2부터는 세 모델 추정값의 중앙값을 숫자로 보여주고 예측 차이를 참고 안내로 표시합니다.**
- 8.2부터는 보조 모델을 불러오지 못해도 유효한 모델 결과가 있다면 숫자를 표시하고, 모델 수가 부족함을 안내합니다.
- 나이 결과를 보류하더라도 **첫인상·피부 및 머리카락 관찰·피부 건강 상식**은 그대로 볼 수 있습니다.
- 두 모델이 크게 다르지 않을 때에도 결과 아래에 모델별 추정값의 **차이**를 표시합니다. 어느 한 모델이 더 정확하다는 뜻이 아니며, *12세라는 구분선은 검증된 확률이나 의학적 기준이 아닌 서비스 운영상의 참고 규칙*입니다.
- 나이 수치를 임의로 더하거나 빼거나, 실제 나이 입력값으로 정답을 만들어내지 않습니다.
- 정확한 나이 추정 성능을 보증하려면 실제 연령과 사진 사용 허가가 확인된 독립 평가 데이터셋으로 검증하고, 연령대·촬영 조건 등에 따른 성능을 측정해야 합니다.

실제 브라우저 테스트에서 동일한 얼굴 사진에 FaceRes **16.2세**, SSR-Net **29.3세**가 출력되는 것을 확인했습니다. 기존처럼 16세를 확정 표시하는 대신 이 사진에 대해서는 *판단 어려움*을 제시합니다.

## 분석 설계에서 중요한 점

**최종 나이 숫자**는 얼굴 나이 예측 모델의 `face.age` 값입니다. 피부·머리카락의 세부 항목은 **별도로 산출되는 설명용 시각 지표**입니다. 실제 나이와의 관계가 검증되지 않은 피부·헤어 가중치로 나이를 임의 보정하지 않습니다.

특히 사진 한 장의 머리카락 픽셀 면적은 **머리숱, 모발 굵기, 두피 노출도, 탈모 정도**와 동의어가 아닙니다. 머리 길이·스타일·프레임 자르기·배경·조명에 크게 좌우됩니다. 앱은 두피나 피부의 건강 상태를 진단하지 않습니다. 주름의 개수, 모공·수분 상태, 실제 피부 나이도 검사하지 않습니다.

네이버/구글 이미지 검색 결과는 사진에 나온 사람의 실제 나이를 검증할 수 없고 저작권·사용 허가 문제가 있을 수 있어 자동 수집하지 않습니다. 비교 데이터셋을 구축하려면 실제 연령 라벨과 사용 허가가 확인된 이미지를 따로 확보해야 합니다.

## 실행 방법

폴더에 `index.html`, `style.css`, `app.js`, `visual-analysis.js`, `verdict.js`, `appearance-feedback.js` 파일이 있어야 합니다.

1. ZIP 압축을 풉니다.
2. 폴더에서 로컬 정적 서버를 시작합니다.

```bash
python -m http.server 8080
```

3. `http://localhost:8080`에 접속합니다.
4. 사진을 올리고, 필수 성별을 선택합니다. 실제 나이는 동안/성숙 멘트를 비교하고 싶을 때만 입력합니다.
5. **결과 보기**를 누르면 얼굴 나이, 첫인상, 관리 코멘트, 얼굴 세부 분석과 피부 건강 상식 카드 6개가 함께 표시됩니다.

> `index.html`을 더블클릭해 `file://`로 열면 JavaScript 모듈의 CORS 제한으로 실행되지 않을 수 있습니다. 반드시 로컬 서버 또는 Vercel 같은 HTTPS 정적 호스팅을 사용하세요.

## Vercel 무료 배포 방법

1. 압축을 풀고 **폴더 내부 파일들**을 GitHub 저장소 첫 화면(루트)에 올립니다.
2. Vercel에서 **새 프로젝트 추가 → 프로젝트 → Git 저장소 가져오기** 순서로 저장소를 불러옵니다.
3. 프레임워크 설정은 **Other(기타)**, 빌드 명령은 **빈칸**, 출력 폴더는 **.** 로 둡니다.
4. **배포**를 눌러 발급받은 HTTPS 주소로 실행합니다.

서버 측 API, API 키, DB, 환경변수는 필요하지 않습니다. 브라우저가 모델을 다운받으므로 최초 분석에는 인터넷 연결이 필요합니다.

## 장애 대응

- **얼굴을 못 찾음**: 정면·선명·가리지 않은 1인 사진으로 다시 시도
- **인공지능 모델 다운로드 실패**: 인터넷, WASM, WebGL, CDN 차단 여부 확인
- **피부·헤어 항목 측정 불가**: 분할 모델을 받지 못했거나 사진에서 해당 부위가 충분히 보이지 않는 경우. 이때도 얼굴 나이는 표시될 수 있음
- **결과가 실제 나이와 다름**: 조명·보정·촬영 각도·표정·학습 모델의 편향 등에 따라 결과가 바뀜

## 정확도와 표현에 대한 주의

- Human 나이 모델은 얼굴 이미지의 여러 시각 단서로 학습된 블랙박스 모델입니다. 표정/잔선/머리카락의 기여도를 각각 측정하는 기술은 사용하지 않습니다.
- `표정`은 이미지 모양만 분류합니다. 개인의 실제 감정·기분을 읽는 기능이 아닙니다.
- `주름 유사 잔선`은 명암 변화로 측정한 참고 신호일 뿐, 주름을 세거나 피부 나이를 진단하지 않습니다.
- 성별은 필수 입력값이지만 나이 계산에 성별 기반의 임의 가산/감산을 하지 않습니다.
- 동안·성숙 멘트는 입력한 실제 나이와 예측치의 차이에 근거한 오락용 문구입니다.
