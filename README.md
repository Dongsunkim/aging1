# 몇살로보여? — 웹앱 한글판 7.0

**사진과 필수 성별을 입력하면 AI 외모 나이를 추정하고, 표정·주름과 유사한 잔선·피부 밝기·가시적 머리카락 영역을 함께 설명하는 웹앱**입니다. 모바일과 컴퓨터를 모두 지원하며 별도 서버 없이 정적 호스팅할 수 있습니다.

## 7.0에서 개선한 화면과 피부 관리 상식

- **성별 필수 선택은 남성·여성만 제공합니다.**
- 사진 분석이 기기 내부에서 이뤄진다는 안내는 화면 맨 위에 한 번만 표시합니다. 상단 추가 표기와 맨 아래 중복 안내를 없앴습니다.
- **‘근거 자료 확인’ 버튼과 링크 문구는 웹앱 화면에서 삭제**했습니다.
- 결과 화면의 피부 관리 상식은 피부 타입과 성분 선택에 도움이 되는 다음 6개 주제로 바꿨습니다.
  - 건조한 피부: 세라마이드·글리세린·히알루론산, 크림과 젤 제형 차이
  - 잔주름: 레티놀·레티노이드 사용 간격, 자외선 차단, 임신 시 사용 금지
  - 잡티·색소침착: 산화철이 들어간 색조 자외선 차단제의 역할
  - 막힌 모공·블랙헤드: 살리실산과 과도한 각질 관리 주의점
  - 새 화장품: 팔 안쪽에서 7~10일간 미리 시험하는 방법
  - 피부 타입별 보습제: 지성·건성·복합성에 따른 제형 선택
- 해당 지식은 **모든 사용자에게 동일하게 표시하는 일반적인 정보**입니다. 사진만으로 피부 수분량이나 질환을 추정하거나 피부 상태에 맞춘 치료를 권하는 기능은 아닙니다.

## 주요 기능

- **첫인상 코멘트**: 사진 속 표정에서 보이는 분위기를 한 문장으로 설명합니다(성격이나 실제 감정 판단 아님).
- **보완 팁**: 조명, 표정, 구도, 사진 속 피부 명암 등 관찰 가능한 요소를 바탕으로 한 가지 실용적인 연출·촬영 조언을 제공합니다.
- 코멘트는 실제 사진 분석에서 나온 단서에 따른 규칙 기반 문구입니다. 별도의 생성형 인공지능이 임의로 진단하는 기능은 아닙니다.
- 나이·첫인상·관리 팁을 결과 복사에 함께 포함합니다.


- **정식 앱 이름: 몇살로보여?**
- 사진 1장 업로드 (그림 파일: JPG, PNG, WEBP, 12MB 이내)
- **성별 필수 선택**: 남성 / 여성. 성별은 표시용 입력이며 추정 나이를 인위적으로 조정하지 않습니다.
- **실제 나이 선택 입력**: 입력 시 예측 나이와 비교하여 결과별 재미있는 문구가 나타납니다. 비워두면 나이 비교 없이 중립적인 멘트가 나옵니다.
- 메인 버튼 **‘결과 보기’** 클릭 시 분석을 시작하고 나이·재미 멘트·세부 결과를 공개합니다.
- 사진 속 표정 모양(미소 등) 참고 정보 (Human 표정 분류 기능). 실제 감정 판정이 아닙니다.
- 얼굴 1명 인식 및 AI 외모 나이 추정 (`@vladmandic/human`)
- **피부·모발 픽셀 분할** (`@mediapipe/tasks-vision`, SelfieMulticlass)
  - 피부의 사진상 밝기·색감 편차
  - 피부 부위의 국소 명암 변화(미세 무늬·잔선 *참고 단서*)
  - 사진에 나타난 상단 머리카락 픽셀의 영역 비율 (실제 머리숱/모발 밀도와 다름)
- 조명/사진 밝기 참고값 및 측정 제한 표시
- 결과 복사, 다시 업로드
- 사용자 사진 저장·업로드 기능 없음: 브라우저 내부에서만 캔버스 화면을 분석

## 분석 설계에서 중요한 점

**최종 나이 숫자**는 얼굴 나이 예측 모델의 `face.age` 값입니다. 피부·머리카락의 세부 항목은 **별도로 산출되는 설명용 시각 지표**입니다. 실제 나이와의 관계가 검증되지 않은 피부·헤어 가중치로 나이를 임의 보정하지 않습니다.

특히 사진 한 장의 머리카락 픽셀 면적은 **머리숱, 모발 굵기, 두피 노출도, 탈모 정도**와 동의어가 아닙니다. 머리 길이·스타일·프레임 자르기·배경·조명에 크게 좌우됩니다. 앱은 두피나 피부의 건강 상태를 진단하지 않습니다. 주름의 개수, 모공·수분 상태, 실제 피부 나이도 검사하지 않습니다.

네이버/구글 이미지 검색 결과는 사진에 나온 사람의 실제 나이를 검증할 수 없고 저작권·사용 허가 문제가 있을 수 있어 자동 수집하지 않습니다. 비교 데이터셋을 구축하려면 실제 연령 라벨과 사용 허가가 확인된 이미지를 따로 확보해야 합니다.

## 실행 방법

폴더에 `index.html`, `style.css`, `app.js`, `visual-analysis.js`, `verdict.js`, `appearance-feedback.js` 파일이 있어야 합니다.

1. ZIP 압축을 풉니다.
2. 폴더에서 로컬 정적 서버를 시작합니다.

```bash
python -m http.server 8080
```

3. `http://localhost:8080`에 접속합니다.
4. 사진을 올리고, 필수 성별을 선택합니다. 실제 나이는 동안/성숙 멘트를 비교하고 싶을 때만 입력합니다.
5. **결과 보기**를 누르면 얼굴 나이, 첫인상, 관리 코멘트, 얼굴 세부 분석과 피부 건강 상식 카드 6개가 함께 표시됩니다.

> `index.html`을 더블클릭해 `file://`로 열면 JavaScript 모듈의 CORS 제한으로 실행되지 않을 수 있습니다. 반드시 로컬 서버 또는 Vercel 같은 HTTPS 정적 호스팅을 사용하세요.

## Vercel 무료 배포 방법

1. 압축을 풀고 **폴더 내부 파일들**을 GitHub 저장소 첫 화면(루트)에 올립니다.
2. Vercel에서 **새 프로젝트 추가 → 프로젝트 → Git 저장소 가져오기** 순서로 저장소를 불러옵니다.
3. 프레임워크 설정은 **Other(기타)**, 빌드 명령은 **빈칸**, 출력 폴더는 **.** 로 둡니다.
4. **배포**를 눌러 발급받은 HTTPS 주소로 실행합니다.

서버 측 API, API 키, DB, 환경변수는 필요하지 않습니다. 브라우저가 모델을 다운받으므로 최초 분석에는 인터넷 연결이 필요합니다.

각 모델은 외부 CDN에서 **다운로드**되며 사용자의 얼굴 사진 파일 자체는 모델 서버나 API에 전송하지 않습니다. 외부 라이브러리의 네트워크 요청 과정에서 일반 접속 메타데이터 및 라이브러리별 텔레메트리가 발생할 수 있습니다. 운영 서비스로 공개하기 전에는 각 라이브러리의 라이선스·개인정보 관련 안내를 검토하세요.

## 장애 대응

- **얼굴을 못 찾음**: 정면·선명·가리지 않은 1인 사진으로 다시 시도
- **인공지능 모델 다운로드 실패**: 인터넷, WASM, WebGL, CDN 차단 여부 확인
- **피부·헤어 항목 측정 불가**: 분할 모델을 받지 못했거나 사진에서 해당 부위가 충분히 보이지 않는 경우. 이때도 얼굴 나이는 표시될 수 있음
- **결과가 실제 나이와 다름**: 조명·보정·촬영 각도·표정·학습 모델의 편향 등에 따라 결과가 바뀜

- 실제 38세 · AI 추정 31세 → `동안이시네요~ ✨`
- 실제 29세 · AI 추정 35세 → `앗, 오늘은 조금 성숙해 보여요~ 😅`
- 실제 30세 · AI 추정 31세 → `와, 또래 느낌이 딱이에요! 🎯`
- 실제 나이 미입력 → `오늘 AI의 촉은 어떨까요? 😎` (동안/노안 표현을 근거 없이 만들지 않음)

## 정확도와 표현에 대한 주의

- Human 나이 모델은 얼굴 이미지의 여러 시각 단서로 학습된 블랙박스 모델입니다. 표정/잔선/머리카락의 기여도를 각각 측정하는 기술은 사용하지 않습니다.
- `표정`은 이미지 모양만 분류합니다. 개인의 실제 감정·기분을 읽는 기능이 아닙니다.
- `주름 유사 잔선`은 명암 변화로 측정한 참고 신호일 뿐, 주름을 세거나 피부 나이를 진단하지 않습니다.
- 성별은 필수 입력값이지만 나이 계산에 성별 기반의 임의 가산/감산을 하지 않습니다.
- 동안·성숙 멘트는 입력한 실제 나이와 예측치의 차이에 근거한 오락용 문구입니다.
